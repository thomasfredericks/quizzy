# Expérience multimédia

## Une expérience multimédia est :

- [ ] Un logiciel informatique
- [x] Un parcours créé à partir de plusieurs médias
- [ ] Une œuvre uniquement audiovisuelle
- [ ] Une activité interactive

## L'expérience multimédia est nécessairement interactive.

- [ ] Vrai
- [x] Faux


## Que va afficher ce code si `x` vaut 5 ?

```c
if (x > 5) {
    printf("Grand");
} else {
    printf("Petit ou égal");
}
```

- [ ] Grand
- [x] Petit ou égal  
- [ ] Les deux  
- [ ]  Rien  


## Laquelle de ces fonctions est correctement structurée ?

- [x]

```c
void test(int x) {
    if (x > 0) {
        printf("Positif");
    } else {
        printf("Non positif");
    }
}
```

- [ ]

```c
void test(int x) (
    if x > 0 {
        printf("Positif");
    }
)
```

- [ ]

```c
void test(int x) {
    if x > 0 [
        printf("Positif");
    ]
}
```

- [ ]

```c
void test(int x) {
    if (x > 0) (
        printf("Positif");
    )
}
```
